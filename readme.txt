2년전인가 3년전에
1학년때 토이프로젝트로 만듬 

기본적으로 술취한사람이 집에 들어가면 끝나는 게임
술취한 사람이라 상하좌우 랜덤으로 이동함.

10x10맵을 4사분면으로 나눠서
1사분면에 술집이 랜덤으로 생성되면 3사분면에 집이 생성
또는 2사분면에 술집에 생성되면 4분면에 집이 생성 반대도 똑같이

한놈이 술집에서 나와서 한명을 끌고가는데
1칸 떨어지면 아마 1/3확률로 댕겨지고
2칸 떨어지면 2/3확률로 댕겨지고
3칸이상 떨어지면 100퍼 확률로 댕겨짐.

그리고 술집에서 나와서 집에 있는 사분면에 진입하면 
다른 사분면으로 안나감.
